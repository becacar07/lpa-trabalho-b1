# Trabalho B1 - Lógica de Programação e Algoritmos

## Descrição
Programa em C que simula o atendimento de uma empresa de entregas: calcula o valor de
cada entrega com base em distância, peso, modalidade, proteção adicional e tentativas
extras, e no final mostra um resumo da sessão.

## Funcionalidades
- Calcula o valor da entrega (distância + peso + modalidade + proteção + tentativas).
- Valida todas as entradas do usuário.
- Processa várias entregas seguidas.
- Mostra um resumo final (total, média, quantidade por modalidade, maior e menor valor).

## Organização da solução
O programa é dividido em funções: leitura/validação de dados, cálculo do valor da
entrega e exibição do resumo. A `main` só coordena o fluxo, chamando essas funções.

## Compilação
gcc -o sim main.c
